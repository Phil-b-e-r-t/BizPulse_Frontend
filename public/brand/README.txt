Put your images in this folder (same folder as this file):

  logo.png        Square logo, at least 128x128, transparent background. Shown in the sidebar, header and login page.
  favicon.png     Browser tab icon, 64x64 or larger.
  auth-bg-1.png   OPTIONAL. Four images (auth-bg-1.png to auth-bg-4.png) that fade and slowly zoom in turn behind
  auth-bg-2.png   the left panel of the login/register screens (landscape, about 1600x1200). They are shown darkened.
  auth-bg-3.png   Any missing file is skipped; if none exist, a plain dark panel is used.
  auth-bg-4.png

If logo.png is missing the app shows a built-in BizPulse mark, so nothing breaks.
